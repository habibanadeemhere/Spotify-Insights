# Spotify Insights — Beyond the Streams

An interactive music analytics project exploring Spotify streaming trends and music performance across Spotify, YouTube and TikTok.

## Live Dashboard

https://spotify-streaming-analytics.streamlit.app/

## Project Overview

This project uses Python to explore music streaming data, identify popular tracks and artists, and understand relationships between different music platforms.

## Key Features

- Interactive Streamlit dashboard
- Music performance statistics
- Artist and track analysis
- Spotify streaming trends
- YouTube and TikTok engagement analysis
- Interactive charts and visualizations
- Data filtering and exploration
- Exploratory Data Analysis (EDA)

## Dataset

**Dataset:** Most Streamed Spotify Songs 2024

**Source:** Kaggle

https://www.kaggle.com/datasets/nelgiriyewithana/most-streamed-spotify-songs-2024

The dataset contains information about music tracks, artists, Spotify streams, playlist reach, YouTube views, TikTok engagement and other music statistics.

## Run Locally

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd Spotify-Insights
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the dashboard

```bash
streamlit run app.py
```
